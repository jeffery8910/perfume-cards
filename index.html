加入新的品牌或組合

  1. 1. 新增香水到「新增香水」頁填表，會產生一個資料檔，按按鈕就能在 GitHub 建立它。
  2. 2. 上傳照片把瓶身照上傳到 img/品牌/，檔名和資料檔裡寫的一樣。
  3. 3. 建立組合在「新增香水」頁切到「新增組合」，選基底和候選香水，產生組合檔。
  4. 4. 匯出圖片推上 GitHub 後，Actions 會自動截出每張卡的 PNG，在 Actions 頁面下載。
